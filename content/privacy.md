The editor processes game data locally and does not require an account or online editing service. The manual also keeps search queries in your browser.

## Files and network access

The application reads the game installation and creates projects, reports and exported mods only through the documented local workflows. It does not modify vanilla game files. Settings and cache data use the [application user-data directory](settings.html#user-data-locations).

Normal editing has no telemetry, remote content or background model/data downloads. Choosing a manual, repository or issue link opens an external website in your browser. That website's own network and privacy behavior applies.

The generated manual uses local styles, scripts, images and system fonts. Its browser search is local. It stores only its chosen color-theme preference. Hosting providers may process ordinary access requests when you visit the hosted site.

## Backups and sharing

Keep backups of native projects, especially before migration. Reports and projects can contain location identifiers, game-derived data and your edits. Inspect them before sharing. Remove personal filesystem paths from issue reports and screenshots.

The source repository and release packages do not include proprietary game files. Users supply their own installed game data. An exported mod can include game-derived population content; this software's license does not grant rights over that game content.
